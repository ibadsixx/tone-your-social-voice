# robots.txt for Tone.
#
# This file is a crawl BUDGET hint, not a security control. Nothing here is
# load-bearing for privacy: an unauthenticated requester can always read the
# robots.txt and then request the URL anyway, and a disallowed URL that a crawler
# already knows is still reachable. Every privacy decision is made by the Gateway
# from the row's own `audience` column, which refuses friends-only / Only-Me /
# draft content to anonymous callers regardless of who is asking (do.md §6, §16).
#
# Concretely, that means:
#   - the Disallow rules below exist to stop crawlers wasting budget on pages
#     that can only ever be a login wall, NOT to hide private content
#   - public content URLs are explicitly ALLOWED, because a Disallow here would
#     make a public post permanently unindexable
#   - private content is never listed here either way: it is not linked, and the
#     Gateway returns 404 for it to an anonymous caller

# Explicitly allow the public content URLs. Most-specific-match wins in the
# robots spec, so without these, a user-agent that matched a later, broader
# Disallow could have public posts excluded. Public Post/Reel/Photo pages are the
# whole point of this file - they must stay crawlable.
User-agent: *
Allow: /post/
Allow: /reel/
Allow: /photo/
Allow: /profile/
Allow: /search
Allow: /groups/
Allow: /pages/
Allow: /hashtag/
Allow: /explore/
